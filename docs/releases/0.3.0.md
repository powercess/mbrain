# MBrain 0.3.0

本版本增加手机操作包和应用诊断包。启用 Root 或 Shizuku 后，工具会随对应来源出现在工具目录中；无需配置外部自动化应用。

## 手机操作包

- 控件树：读取当前窗口的文字、描述、资源 ID、坐标、父子关系和可操作状态，支持分页。
- 点击与长按：按文字、资源 ID、描述定位，也支持坐标操作；多个匹配需明确选择。
- 中文输入：替换输入框内容，支持中文、emoji 和多行文本，可通过输入框标签定位。
- 滑动与导航：滑动、返回、桌面、最近任务、通知栏和快捷设置。
- 等待：等待控件出现或消失，超时明确返回错误。
- 剪贴板：读取和写入文本。

## 应用诊断包

- 日志：按进程、UID、标签、级别、缓冲区和起始时间查询。
- AppOps：读取、修改单项操作模式，并返回修改后的查询结果。
- 进程与资源：进程列表、RSS、应用内存报告和 CPU 采样报告。
- 网络：IP、路由、Wi-Fi、代理状态，以及 DNS 解析和 TCP 连通性诊断。

## 使用范围

新增 16 个工具，每个已启用的高权限来源分别注册 `root_` 或 `shizuku_` 前缀。工具目录提供对应中文名称。现有工具和配置保持兼容。

开发版固定使用 `com.powercess.mbrain.dev`，桌面名称为“MBrain 开发版”；包名不随版本变化，后续使用相同本地签名覆盖更新。正式版仍使用 `com.powercess.mbrain`。

手机操作针对当前活动窗口和默认显示器，设备需要处于可交互状态。自绘控件、受保护页面可能不提供完整控件树。剪贴板、系统命令及隐藏接口受 Android 版本和厂商系统影响，不可用时返回明确错误，不自动切换执行身份。

# MBrain 0.2.0

## 内网穿透

- 新增独立服务器配置入口，所有隧道共用一台 frps 服务器。
- 简化服务器和隧道配置，仅提供基础 TCP 转发，移除 HTTPS 插件和证书管理界面。
- MCP 隧道转发本机网关 `127.0.0.1:8765`，公网访问端口独立配置；自动生成 MCP 访问地址并支持复制客户端配置。
- 精简隧道详情页，将连接诊断和运行记录收纳到“更多”。
- 修复要求 TLS 的 frps 登录失败，保留底层连接加密，并合并重复重连错误。

## 升级说明

- 旧服务器配置会自动整理；旧多服务器数据保留，当前仅支持使用第一台服务器。
- 旧 HTTPS、插件和证书配置需重新编辑为 TCP 后才能启动。
- 应用重启或升级后，需手动启动网关和隧道。
- frps Token 用于服务器登录，MCP Token 用于公网 MCP 请求鉴权，两者独立。

## 验证

- 已在测试设备验证公网 MCP 鉴权、初始化、工具发现和设备、电量、网络、存储四项只读工具调用。

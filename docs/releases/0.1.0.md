# MBrain 0.1.0

MBrain 首个正式版本：让支持 MCP 的 AI 客户端调用 Android 设备能力。

- 查看设备状态、电量、存储与网络信息，查询和管理应用。
- 按需启用 Root / Shizuku，执行命令与文件操作。
- 接入本机 HTTP MCP 服务，或托管 stdio MCP 进程，统一提供工具入口。
- 底部导航、首页悬浮启停按钮、工具搜索和浅色 / 深色主题。

## 安装

下载 `mbrain-v0.1.0-universal.apk`，支持 Android 9.0+，覆盖 ARM64、ARM32、x86_64 和 x86。
正式包名为 `com.powercess.mbrain`，使用固定正式签名。

早期临时 Debug 包若使用相同包名，将不能直接覆盖为正式版。卸载会清除应用配置，请先保存需要保留的连接设置。后续测试包使用 `com.powercess.mbrain.debug`，可与正式版并存。

## 连接与权限

启动网关后，在客户端填写 `http://127.0.0.1:8765/mcp` 和本次启动的 Bearer Token。电脑连接可使用 `adb forward tcp:8765 tcp:8765`。

Root / Shizuku 按需启用；持有 Token 的客户端可以使用全部已启用工具。请只连接可信客户端。

## 校验

`SHA256SUMS.txt` 提供 APK 文件校验值，`SIGNING_CERTIFICATE.txt` 提供签名证书的 SHA-256 指纹。使用说明见仓库 README。
